  v2.50.0 — Chrome Extension Data Importer (Mar 2026)
================================================================================

  Chrome Extension (Side Panel)
  - Chrome extension with right-hand side panel (like Claude extension)
  - Auto-detects DAO Dashboard vs WebSnak from current tab URL
  - "Import DAO Dashboard" button scrapes all transaction pages
  - "Import WebSnak Stores" button scrapes all store pages with auto-pagination
  - Activity log in sidebar shows scrape progress, success, and errors
  - Sidebar auto-updates when switching tabs or navigating
  - Scraped data sent directly to Map Tracker app via postMessage
  - DAO import: auto-imports transactions + syncs last sale dates on stores
  - WebSnak import: loads store data into Data Import for review and apply
  - Host permissions for daogroup.com, allFrames for iframe support
  - Load as unpacked extension from scripts/chrome-extension/

  v2.49.0 — Travel Log Redesign & Store Search (Mar 2026)
================================================================================

  Travel Log Layout
  - Side-by-side layout: map on left (612px sidebar), data panels on right
  - Breadcrumbs and Driving Periods panels stacked vertically on right
  - 2-row header: title + stat badges (top), vehicle/filters/actions (bottom)
  - Stats condensed into compact inline badges (stores, wh, drives, mi, mpg)
  - Responsive: stacks vertically on screens under 900px

  Store Search
  - Data/Search toggle button in filter bar to switch right panel mode
  - Search stores by name, ID, city, address, or route number
  - Shows 3 most recent visits (grouped by date, not individual entries)
  - Visit details: date, arrival, departure, total dwell, vehicle
  - Mini calendar below table showing current + previous month
  - Visit dates highlighted as green circles on calendar
  - Map flies to selected store with purple star marker

  Map Alerts
  - Fix: map alert count now matches Alert Log open count
  - Map only shows truly open alerts (excludes completed and done alerts)
  - AlertLog still shows completed/done alerts for the week as before

  v2.47.0 — WhatsApp All-Chat, Inventory Cards, Map Alerts (Mar 2026)
================================================================================

  WhatsApp
  - All-chat toggle: show every message from all contacts in one flat
    chronological view (toggle between grouped and flat with one button)
  - Paste Order feature: paste formatted order text into WhatsApp tab,
    creates a synthetic message from "Visual Basic" that can be processed
    with Create Order
  - Fix: manual/pasted messages no longer disappear when the 5-second
    poll cycle refreshes the inbox

  Inventory
  - Redesigned summary cards: replaced generic totals (Total Ordered,
    Sold, In Stock, Products) with meaningful data
  - New cards: Next Delivery date, $4.79 Sold This Week, $.50 Sold This
    Week, $2.49 Sold This Week, Deep River This Week
  - Weekly sales now pull directly from warehouse orders by item.category
    instead of inventory orderDeductions (more reliable)

  Map / Alerts
  - Alert exclamation marks default to hidden (toggle via legend checkbox)
  - When Alerts checkbox is checked, non-alert stores are hidden
  - Pulsing animation only on yellow-tier stores (11-15 days since visit)
  - Alert count shown in legend label: "Alerts (5)"
  - Fix: WhatsApp alert image sending now works (fixed stale closure bug
    where alertImages reference was outdated after async fetch)

  Alert Log
  - Header redesigned from one long row into two organized rows:
    top bar (title, stats, actions) + filter bar (search, filters)
  - WhatsApp settings section sits between the two rows

  Orders Data
  - Fixed Eastern Shore order: SKU 028663 had cases set to 60663 (SKU
    number leaked into cases field); corrected to 12 items, 240 cases
