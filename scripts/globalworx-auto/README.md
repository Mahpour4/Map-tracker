# GlobalWorx Auto-Acknowledger

Automatically reads unread GlobalWorx alert emails from Gmail, extracts the acceptance link from the email body, fills the form via headless Chrome, and labels the email as **Processed**.

---

## What it does

1. Searches Gmail for unread emails matching `from:goglobalworx.com`
2. Reads the full email body (HTML + plain text) and locates the acceptance URL
3. Opens the URL in headless Chrome (Puppeteer) and:
   - Clicks **"Accept Here"**
   - Selects the **"48 hours"** resolution window from the dropdown
   - Fills the **comment**: *Acknowledging issue — will resolve within 48 hours.*
   - Fills the **name**: *Wise Office*
   - Clicks **"Accept Issue"**
4. Applies the **"Processed"** Gmail label and marks the email as read
5. Repeats every **2 minutes** (configurable)

---

## Setup

### 1. Install dependencies

```bash
cd scripts/globalworx-auto
npm install
```

### 2. Create a Google Cloud project & enable Gmail API

1. Go to https://console.cloud.google.com/
2. Create a new project (or select an existing one)
3. Navigate to **APIs & Services → Library**
4. Search for **Gmail API** and click **Enable**

### 3. Create OAuth2 credentials

1. Go to **APIs & Services → Credentials**
2. Click **Create Credentials → OAuth client ID**
3. Application type: **Desktop app**
4. Name it anything (e.g. "GlobalWorx Auto")
5. Click **Create**
6. Download the JSON file and save it as **`client_secret.json`** in this folder

### 4. Authorise the app (one-time)

```bash
node auth.js
```

- Opens a browser URL — paste it into your browser
- Grant the requested Gmail permissions
- Copy the authorisation code and paste it back into the terminal
- This saves `credentials.json` in this folder

### 5. Run

```bash
node index.js
```

## Configuration

Edit the `CONFIG` block at the top of `index.js`:

| Key | Default | Description |
|-----|---------|-------------|
| `PROCESSED_LABEL` | `"Processed"` | Gmail label applied after processing |
| `POLL_INTERVAL_MS` | `120000` (2 min) | How often to check. Set to `0` to run once |
| `FORM.name` | `"Wise Office"` | Name filled in the acceptance form |
| `FORM.comment` | `"Acknowledging issue…"` | Comment filled in the acceptance form |
| `FORM.resolutionText` | `"48"` | Text to match in the resolution dropdown |
| `GMAIL_QUERY` | `is:unread from:goglobalworx.com` | Gmail search query |

## Security notes

- `client_secret.json` and `credentials.json` are in `.gitignore` — never commit them
- The script only requests `gmail.readonly`, `gmail.modify`, and `gmail.labels` scopes
- Puppeteer runs in headless mode with `--no-sandbox` for compatibility

## Troubleshooting

**"Could not find element with text Accept Here"**
The GlobalWorx page layout may have changed. Open `index.js`, find `submitAcceptanceForm`, and update the button text strings to match the current form.

**"No GlobalWorx acceptance link found in email body"**
The email body preview is logged — check if the URL format has changed and update `URL_PATTERN` or `FALLBACK_URL_PATTERN` in `CONFIG`.

**Token expired errors**
Delete `credentials.json` and run `node auth.js` again.
